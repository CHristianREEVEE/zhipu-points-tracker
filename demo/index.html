AgentMore 积分：余额 · 消耗趋势 · 任务明细 —— 网页面板 + Electron 半透明置顶悬浮窗，服务器 5 分钟自动记账，token 滚动续期 180 天免登录。

桌面悬浮窗

时钟（秒级）· 余额 · 今日/昨日消耗左右切换 · 最近任务 · 半透明毛玻璃，永远置顶

网页完整面板

每日消耗柱状图（近 14 天，悬停显示数值）· 24h/30日统计 · 变动明细

特性

穿透模式

点击穿透后鼠标直达底层应用，不打断游戏/写作；光标移入自动武装，右键一键恢复。

位置记忆

拖到哪就记到哪（widget.config.json），下次启动原地出现。

自动续期

复刻官方 refresh 端点，token 滚动续 180 天，理论上永久免重登。

数据自治

全部数据落自己服务器（JSON 落盘），密钥墙 + 密钥不进 URL。

零依赖 worker

Python 标准库实现，systemd 常驻，无第三方包。

服务器热更新

悬浮窗页面由服务器实时下发，改功能不用重新打包 exe。

快速开始

① 服务器跑 worker.py（systemd 常驻）→ ② Caddy 挂 /points/* → ③ Electron 包解压双击 exe → ④ F12 抄一次 cookie 粘进面板，此后全自动。

细节见 GitHub 仓库 README（含 AgentMore Web API 逆向要点：时间戳校验位算法 / X-Sign 签名 / WAF 浏览器头 / refresh 滚动续期）。
